# Security policy / 安全政策

发现 AlonaBot 安全漏洞时，请通过 [GitHub 私密漏洞报告](https://github.com/AlonaBot/AlonaBot/security/advisories/new) 联系维护者；维护者在该报告中跟进复现、修复与披露安排。

## 提交报告

请提供：

- 受影响的 commit 或版本、操作系统，以及相关组件和配置。
- 漏洞影响、触发条件和最小复现步骤；可附脱敏的日志或概念验证。
- 已知的缓解措施（如有）。

凭证与真实用户数据请先脱敏；漏洞细节通过私密报告提交。公开披露时间请在报告中与维护者协商。

## 版本范围

项目处于实施初期，安全修复以 `main` 的当前代码为基础。报告旧 commit 的问题时，请注明版本，帮助维护者核对当前代码的影响范围。

普通 Bug 使用 [Issue 表单](https://github.com/AlonaBot/AlonaBot/issues/new/choose)，使用求助与方案交流前往 [讨论区](https://github.com/AlonaBot/AlonaBot/discussions)。

## Report a vulnerability

Contact maintainers through [GitHub private vulnerability reporting](https://github.com/AlonaBot/AlonaBot/security/advisories/new). Include:

- The affected commit or version, operating system, components and relevant configuration.
- Impact, trigger conditions and minimal reproduction steps; sanitized logs or a proof of concept can help.
- Known mitigations, if available.

Remove credentials and real user data before sharing. Maintainers coordinate reproduction, fixes and disclosure within the private report; agree on public disclosure timing there.

## Supported versions

AlonaBot is in early implementation. Security fixes target current `main`; include the affected version when reporting an older commit so maintainers can assess current impact.

Use the [Issue forms](https://github.com/AlonaBot/AlonaBot/issues/new/choose) for ordinary bugs and [Discussions](https://github.com/AlonaBot/AlonaBot/discussions) for usage questions.
