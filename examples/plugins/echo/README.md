# Echo example

[简体中文](README.zh-CN.md)

Send plain text or an image and the plugin echoes the text and incoming image. After a command, text match or Raw handler consumes an event, the event echo reads Core's consumption state with `sdk.NotCommand()` to avoid duplicate replies.

Check and build from the repository root:

```fish
go run ./cmd/alonabot check examples/plugins/echo
go run ./cmd/alonabot build examples/plugins/echo --out /tmp/alonabot-echo
```

For Telegram configuration and the shared echo/media startup command, see the [media example](../media/README.md).

| Input | Behavior and API |
| --- | --- |
| `/echo hello world` | `p.Command(...).Args(...).Optional(...).RawTail().Handle(echoText)` explicitly binds a package function and uses `c.Reply`; omitted text replies with `echo` |
| `/note add first  note`, `/n add second note` | `Group("note")` in subplugin `notebook`; positional `RawTail` retains internal whitespace and method values bind an explicitly created `notebook` object |
| `/note list`, `/n list` | Both commands declare complete `/n` subcommand aliases and list notes from the same object |
| `/calc 4`, `/calc 4 3` | The `arg`/`default` tags on `Calculation` produce `5` and `7`; returning `(message.Content, error)` replies automatically |
| `roll 2d6` | Regex reads two captures through `c.Match()` and replies `Rolling 2d6.` to demonstrate capture arguments |
| `ECHO EXAMPLE KEYWORD` | A dedicated keyword with `IgnoreCase` returns one automatic reply |
| `echo example raw` | The Raw Go Rule accepts only this dedicated input; other plain text and images retain the existing echo behavior |
| `/ask` | A trusted-user command enters a continuation through `.Continue()`, asks a question and calls `c.Wait(time.Minute)` to echo the next text from the same user and conversation |
| `/note publish`, `/note published` | Publish a typed `NotesSnapshot`; the subscriber saves only the business payload, and the latter command reads the received snapshot |

Each `New()` creates a separate plugin and notebook object. Notes are an in-process demonstration list shared by all users and cleared on restart. The subplugin ID is `notebook`, command paths are `/note ...`, and route_id retains identifiers such as `cmd.note.add` generated by the existing rules.

`notesService = service.JSON[NotesQuery, NotesSnapshot]("echo/notes")` and `service.Serve(p, notesService)` provide a public read-only Service. A caller uses the same type declaration and calls `notesService.Call(c, NotesQuery{})` inside a valid Handler. Cross-plugin projects should share declarations and named types as source. Local verification reuses `commands.go` in a temporary project to build a real caller process. Other activated plugins can read this public demonstration list.

`notesPublished = bus.Define[NotesSnapshot]("echo/notes_published")` is shared by Publish and Subscribe. Successful publication confirms Core acceptance; subscriptions run asynchronously, and `/note published` shows the snapshot received at that moment. Subscription Context has no user Actor or default target; its Handler only needs to save the list.

Adding declarations and messages requires no extra generation step: `alonabot run`, `build` and `go test` scan resources each time. The project contains no generated files.
