# 实施计划：WebUI

总目标、章节划分与跨章节依赖见 [PLAN](../PLAN.md)；本章节的 goal 语句见 [webui.md](../../docs/goals/webui.md)。切片的拆分规则、状态与跨任务验收规则见 [PLAN §3.1](../PLAN.md#31-执行切片) 与 §5。

## 1. 范围

本章节只覆盖官方 WebUI 组件 `web/admin/` 的前端：骨架、配置表单与 i18 组件、管理页面、配置与权限页面以及日志页（T-08.7、T-09.8、T-09.9、T-09.15）。页面调用的 Admin API、管理认证与管理服务层，以及 Core 提供 WebUI 静态文件与组件图标（T-09.12），都在[核心实施计划](core.md)；页面切片以提供其接口的核心切片为前置。本章节没有自己的工作包，步骤文字在核心计划的 T-08 步骤 9 与 T-09 步骤 7。
